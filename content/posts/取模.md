## 概念
对于整数$a$、$b$($b\neq0$)，一定可以唯一写成
$$
a =  b \times q +r
$$
其中，$0 \le r < \left| b \right|$，$q$ 为商，$r$ 为余数也就是取模的结果

## C++中%运算规则
C++的取余结果符号 = 被除数 $a$ 的符号（先计算绝对值对应的余数，再按被除数的符号处理），即：
$$
 a  \%  b = a - (a/b) \times b
$$
注意：C++ 整数除法 `a / b` 向零截断，不是向下取整。例如 `-7 / 3 == -2`，因此 `-7 % 3 == -1`。这与要求余数非负的数学取模需要区分。

参考：[C++ 标准草案：乘除与取余运算](https://eel.is/c++draft/expr.mul)。

## 负数余数转正
当要求余数非负时，则需要将余数转正
$$
res = (a \% mod + mod)\% mod
$$

## 取模与位运算结合

当 $x \ge 0$ 且模数是 $2^k$ 时，有：

$$x \bmod 2^k = x \mathbin{\&} (2^k-1)$$

负整数的 C++ `%` 可能产生负余数，不能直接把它与按位与的结果混为一谈。

## 乘法取模
乘法取模具有以下性质
$$(a \times b ) \% m = ((a \% m) \times (b \% m)) \% m$$
但是当两个大数 $a$ 和 $b$ 做乘法取模时，直接用上述公式可能出错因为可能存在溢出的情况。
下面使用 GCC/Clang 的 `__int128` 保存中间乘积（模数 `m > 0`），避免两个 `long long` 相乘溢出。代码中的 `ll` 表示 `long long`。
```cpp
using ll = long long;

ll mul(ll a, ll b, ll m)
{
    a %= m;
    b %= m;
    if (a < 0) a += m;
    if (b < 0) b += m;
    return static_cast<ll>(static_cast<__int128>(a) * b % m);
}
```

## 幂运算取模
幂运算取模有如下性质
$$
a^n \;mod \;m = (a\;mod\;m)^n\;mod\;m
$$
注意结合快速幂
```cpp
// 前提：n >= 0，mod > 0；mul 使用上面的实现。
ll fastPow(ll a, ll n, ll mod)
{
    ll ans = 1 % mod;
    a %= mod;
    if (a < 0) a += mod;
    while (n > 0)
    {
        if (n & 1) ans = mul(ans, a, mod);
        a = mul(a, a, mod);
        n >>= 1;
    }
    return ans;
}
```
